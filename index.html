How to play

Computer keyboard

  • Z / X octave down / up
  • Space play / stop
  • ← / → previous / next preset
  • ↑ / ↓ turn the focused knob
  • Hold Shift (or the SEL button) and press an upper-row key for its printed function: OP1-OP6 select an operator, MT mutes it, GLO toggles glide, MONO / POLY set voice mode.

Panel

  • Knobs: drag up/down, scroll, or focus and use arrow keys. Double-click resets KNOB1-4.
  • PRESETS picks a patch, ALGORITHM picks one of 14 operator routings, SELECT picks the operator to edit, MASTER is volume.
  • EDIT (ratio, detune, level, feedback), ENV (attack, decay, sustain, release), LFO, FX and GLO pages map their parameters to KNOB1-4.
  • ARP toggles the arpeggiator. SEQ shows the 16-step pattern; REC step-records notes from the keys (tap SEL for a rest).
  • PLAY/STOP plays the selected song, or the step pattern when PATTERN is selected.
  • SAVE stores the edited patch in this browser.
